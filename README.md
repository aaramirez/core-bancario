# Core bancario

El sistema que lleva el saldo de cada cuenta y de cada crédito, contado para cualquier área: el libro mayor, las cuentas y los depósitos, los préstamos, la fábrica de productos, el cierre de cada noche, el tiempo real frente a los lotes, y cómo se moderniza o se migra un core sin perder un centavo.

**Ver en línea:** https://aaramirez.github.io/core-bancario/
